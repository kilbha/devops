########### Installing Jenkins ###############
1. Login to jenkins VM
2. sudo apt update
3. sudo apt install openjdk-17-jre-headless -y
4. Installing Jenkin -- Follow as per veeramalla or google -- https://www.jenkins.io/doc/book/installing/linux/
5. Installing through link -- https://www.jenkins.io/doc/book/installing/linux/
6. Installing docker -- sudo apt install docker.io
7. Enable docker for other users -- sudo chmod 666 /var/run/docker.sock
8. SignIn To Jenkins -- Get password and login. Install suggested plugins
9. Create first admin user
10. Install Plugins -- Manage Jenkins -- Plugins -- Available Plugins -- SonarQubeScanner, Config FIle Provider, Maven Integration, Pipeline maven integration, Kubernetes, Kubernetes Credentials, Kubernetes CLI, KUbernetes Client API, Docker, Docker Pipeline, Eclipse Termurin Installer ( To add different java jdks), Pipeline Stage View. 
11. Configure Plugins by Tools -- Docker installations -- name as docker and install automatically -- Download from docker:latest. 
12. Configure Maven -- Maven Installations -- name as maven3 -- Install automatically -- from apache. 
13. Add SonarQubeScanner by name sonar-scanner -- keep it to latest. 
14. Add JDK by java installations --    Add JDK -- name as jdk17 from install from adoptium.net -- choose 17 version. 
15. New Item -- name as Blogging-app -- Discard old builds -- Max # of builds to keep as 2 -- Script as Hello world piple at the bottom. 
16. Install trivy -- use google. 
17. Cofigure SonarQube -- Manage Jenkins -- Credentials -- global -- Add credentials -- kind as secret-text -- id as sonar-token -- create. 
18. Manage Jenkins -- System -- Scroll down to SonarQube servers -- Add sonarqube -- name as sonar-server -- give server_url till 9000 -- select token -- apply. 
18. script -- uSE PIPELINE SYNTAX for help. 
    pipeline {
        agent any

        tools {
            jdk 'jdk17' -- name we have given.
            maven 'maven3
        }


        environment {
            SCANNER_HOME=  tool "sonar-scanner"
        }

        stages {
            stage('Git checkout') {
                steps{
                    // Generate using pipeline SYNTAX

                }
            }

            stage('Compile'){
                steps {
                    sh "mvn compile"
                }
            }

            stage('Test'){
                steps {
                    sh "mvn test"
                }
            }

            stage('Trivy FS SCAN'){
                steps {
                    sh "trivy fs --format table -o fs.html ."
                }
            }

            stage('SonarQube Analysis'){
                steps {
                    // Generate using pipeline Syntax 
                    withSonarQubeEnv('sonar-server'){
                    sh '''$SCANNER_HOME/bin/sonar-scanner -Dsonar.projectName=Blogging-app -Dsonar.projectKey=Blogging-app \
                            -Dsonar.java.binaries=target'''
                    }
                }
            }

            stage('Build'){
                steps {
                    sh "mvn package"
                }
            }
        }
    }
########### Installing Nexus ####################
1. Login to Nexus VM
2. sudo apt update 
3. Install docker -- sudo apt install docker.io
4. sudo docker run -d -p 8081:8081 sonatype/nexus3
5. sudo docker ps
    ### Takes some time to run it #
6. Get admin password by sudo docker exec -it <docker-container-id> /bin/bash
7. cat sonatype-work/nexus3/admin.password
8. Sign in to nexus and setup new password
9. 

########### Intalling SonarQube #################
1. Login to SonarQube VM
2. sudo apt update
3. sudo apt install docker.io
4. sudo docker run -d -p 9000:9000 sonarqube:lts-community
5. sudo docker ps
6. Login to it. admin, admin -- username, password. setup new password.
