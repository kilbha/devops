########### Installing Nexus ####################
1. Login to Nexus VM
2. sudo apt update 
3. Install docker -- sudo apt install docker.io
4. sudo docker run -d -p 8081:8081 sonatype/nexus3
5. sudo docker ps
    ### Takes some time to run it #
6. Get admin password by sudo docker exec -it <docker-container-id> /bin/bash
7. cat sonatype-work/nexus3/admin.password
8. Sign in to nexus and setup new password
9. We have to add this in pom.xml for Nexus Configuration
    <distributionManagement>
        <repository>
            <id>maven-releases</id>
            <url>http://13.235.245.200:8081/repository/maven-releases/</url>
        </repository>
        <snapshotRepository>
            <id>maven-snapshots</id>
            <url>http://13.235.245.200:8081/repository/maven-snapshots/</url>
        </snapshotRepository>
    </distributionManagement>
10. Go To Jenkins -- Manage Jenkins -- Managed Files -- Add new config -- Global Maven Settings -- ID as maven-settings -- Next -- Add server credentials here 
    <servers>
        <server>
            <id>maven-releases</id>
            <username>admin<username>
            <password><Nexus-Password</password>
        </server>
    </servers>

    <servers>
        <server>
            <id>maven-snapshots</id>
            <username>admin<username>
            <password><Nexus-Password</password>
        </server>
    </servers>
11. Submit
12. Now we are able to communicate with Nexus.

######### Setting UP EKS cluster with Terraform ##################
1. Create Terra-Instance -- t2.medium -- 15GB storage. 
2. sud apt update
3. Install AWS CLI & Configure
4. sudo snap install terraform --class 
5. mkdir Terra
6. cd Terra/
7. vi main.tf -- from repostiory. 
8. vi output.tf -- from repository
9. vi variables.ts -- from repository
10.teraaform init
11. terraform plan
12. terraform apply --auto-approve
13. Install kubectl -- sudo snap install kubectl --classic
14. Connect kubectl to cluster -- aws eks --region ap-south-1 update-kubeconfig --name devopsshack-cluster
15. kubectl get nodes
16. setup RBAC -- vim svc.yml ( outside terra folder) -- under name space webapps
17. kubectl create ns webapps & kubectl apply -f svc.yml 
18. vi role.yml -- get from github
19. kubectl apply -f role.yml
20. Bind role to svc account -- vi bind.yml
21. kubectl apply -f bind.yml 
22. Now -- Jenkins has permissions to update or delete it. 
23. Create token for svc account -- click on link provided in repo  -- copy it
24. vi jen-secret.yml -- change service account name -- apply. 
25. kubectl apply -f jen-secret.yml -n webapps
